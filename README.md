# 마노아 벌레 퇴치단

선크림 소녀와 알파카가 하와이 마노아에서 우리 집을 노리는 지네·바퀴벌레를 퇴치하는 Slay the Spire 스타일 카드 게임. 우리 집 이너서클 전용.

## 하는 법

- 카드를 눌러 고르고, 공격 카드는 적을 눌러서 사용 (끌어다 놓아도 됨). PC에서는 `1`~`9`로 카드 선택, `E`로 턴 종료.
- 적 머리 위 아이콘이 다음 행동: 🗡️ 공격 · 🛡️ 방어 · 💪 강화 · 🌀 약화. 옆 얼굴이 맞을 캐릭터.
- 소녀 카드는 소녀가, 알파카 카드는 알파카가 쓴다. 기절하면 그 캐릭터 카드는 못 쓴다. 둘 다 기절하면 패배.

## 실행

빌드 없이 `index.html`과 `sprites/` 폴더로 돌아간다. 파일을 브라우저로 열거나, GitHub Pages로 올리면 폰에서 바로 할 수 있다. 폰에서 "홈 화면에 추가"하면 앱처럼 전체 화면으로 열린다.

## 밸런스 고치기

`index.html` 스크립트 맨 위 `DATA` 부분에 다 모여 있다.

- `HEROES`: 아군 체력
- `CARDS`, `STARTER`: 카드 효과와 시작 덱 구성
- `ENEMIES`: 적 체력, 행동, 행동 패턴(`ai`)
- `SPRITES`: 캐릭터 그림(`sprites/`), 크기, 애니메이션 재생 순서

## Claude 아티팩트로 게시

아티팩트 호스트가 `<html>/<head>/<body>`를 직접 씌우기 때문에 그 껍데기를 뺀 파일을 따로 만든다.

```sh
scripts/build-artifact.sh   # → dist/artifact.html
```

게시할 때 `sprites/` 아래 PNG(`sprites/cards/` 포함)도 같은 경로로 같이 올린다.

현재 아티팩트: https://claude.ai/artifact/BdnYHQ1pJZoqakaL7ukgc2
